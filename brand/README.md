# Brand files

Designer's original files, never edited. `node dev/brand-assets.mjs` makes every icon and logo size from these.

- symbol.png: the sticker symbol
- wordmark-horizontal.png: symbol + WA Audio Stickers + tricolour INDIA tag + tagline (current, light)
- brand-board.png: lockups, icon sizes and palette
- wordmark-horizontal-dark.png: the same lockup on the dark olive-black background (used as-is for dark mode)
- symbol-on-dark.png: the symbol on the dark background (app icon or avatar use)
